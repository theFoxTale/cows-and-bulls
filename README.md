# Bulls and Cows 🐂🐄

Игра в угадывание секретного числа из уникальных цифр. Компьютер загадывает число заданной длины в выбранной системе счисления, игрок вводит варианты и после каждой попытки получает подсказку: сколько цифр угаданы и стоят на своём месте (**bulls**), сколько угаданы, но стоят не на своём месте (**cows**).

Проект выполнен в рамках задания [RS School](https://rs.school/) и посвящён **архитектуре и функциональному программированию**: вся игровая логика — чистые функции без классов, без побочных эффектов и без зависимости от DOM.

## ✨ Возможности

- Настройка длины секретного числа (2–6 цифр) и системы счисления: `bin` / `oct` / `dec` / `hex`.
- Автоматическое ограничение допустимых длин под выбранную систему (для `bin` доступна только длина 2).
- Поле ввода фильтрует недопустимые символы в реальном времени.
- Регистронезависимый ввод для `hex` (`a` и `A` — одна и та же цифра).
- История попыток с корректными `bulls` / `cows`, пополняется иммутабельно.
- Подсчёт количества попыток и времени с начала раунда.
- Таблица рекордов в `localStorage` — переживает перезагрузку страницы, у каждой записи отображаются настройки раунда.
- «Новая игра» возвращает к экрану настроек без перезагрузки.
- Секретное число хранится как строка — лидирующие нули обрабатываются корректно (`0123` ≠ `123`).

## 🧪 Тестирование

Проект написан по **TDD**: для каждой обязательной функции ядра сначала шёл коммит с падающими тестами, затем — с реализацией. Тесты соответствуют **FIRST**:

- **Fast** — без DOM, без сети, миллисекунды на весь набор;
- **Independent** — каждый тест самодостаточен, нет общего состояния;
- **Repeatable** — генерация случайности детерминирована (передаётся параметром);
- **Self-validating** — каждый тест заканчивается явным `expect`;
- **Timely** — написаны до реализации.

Покрыты все обязательные функции:

- `generateSecret(length, base, random)`
- `evaluateGuess(secret, guess)`
- `isValidGuess(guess, length, base)`
- `createDigitValidator(base)`
- `countPossibleSecrets(length, base)`

Запуск: `npm test`.

## 🏛️ Функциональное программирование

Ключевые решения (подробнее — в [DESIGN.md](./DESIGN.md)):

- **Чистые функции** — всё ядро игры (`src/core/`) не имеет побочных эффектов и не зависит от DOM.
- **Каррирование** — `createDigitValidator(base)` возвращает предикат и используется в двух местах: валидация попытки и фильтрация ввода в реальном времени.
- **Рекурсия + мемоизация** — `countPossibleSecrets` считает P(base, length) через рекурсию с кэшем результатов.
- **HOF вместо циклов** — `evaluateGuess` построен на `map` / `filter` / `reduce`, а не на ручных счётчиках.
- **Иммутабельность** — история попыток и состояние игры обновляются только через создание новых объектов (`[...history, entry]`), без мутаций.
- **Без классов** — игровая логика читается как набор чистых функций.
